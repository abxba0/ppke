> **Note:** The README previously listed hybrid search as "Not implemented". It is fully implemented — `hybrid_search()` in `search.py` does real weighted score fusion, deduplication by `book_folder::paragraph_id`, and tags each result with its source backend (`"hybrid"`, `"vector"`, or `"fulltext"`). Requires `chromadb` package for the vector half; degrades gracefully to full-text only if unavailable.

## 7. Obsidian / PKM Sync

| Feature | Status | Location |
|---------|--------|---------|
| One-time Obsidian ZIP export | Implemented | `graph/analytics.py`, `export/obsidian_sync.py` |
| **Two-way live sync** (`ObsidianSyncEngine`) | **Implemented** | `export/obsidian_sync.py`, `web/app.py /api/obsidian-sync/*` |

> **Note:** The README previously listed "Deep Obsidian/PKM sync" as "Not implemented". `ObsidianSyncEngine` in `export/obsidian_sync.py` is fully implemented with:
> - `sync_to_vault()` — incremental push using SHA-256 content hashing (only changed files written)
> - `sync_from_vault()` — pulls edits made inside Obsidian back into PPKE
> - `full_sync()` — bidirectional in one call
> - `get_status()` — manifest stats without writing
>
> The engine uses `.ppke_sync_manifest.json` to track file state across syncs.
